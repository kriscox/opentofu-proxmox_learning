# Project Roadmap

## Purpose <!-- omit from toc -->

This document describes the high-level roadmap for the OpenTofu-Proxmox learning project.

The roadmap is used to:

- Organize the project into logical phases.
- Keep individual ChatGPT conversations focused.
- Provide a stable navigation structure for the repository.
- Track overall project progress.

The GitHub repository is the project's source of truth. ChatGPT conversations are used to discuss, design and implement individual roadmap items.
